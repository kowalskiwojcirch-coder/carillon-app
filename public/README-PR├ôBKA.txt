TWOJA PRÓBKA DŹWIĘKU

W tym folderze (public) umieść swoją jedną próbkę i nazwij ją dokładnie:
sample.wav

Pełna ścieżka ma wyglądać tak:
public/sample.wav

Obsługiwany i zalecany format: WAV PCM. Po dodaniu pliku przebuduj aplikację w GitHub Actions.
Nie dodawaj próbki przez interfejs aplikacji — wgrywanie plików zostało usunięte.
Punktem odniesienia dla wysokości dźwięku jest C3 (MIDI 48). Wszystkie nuty MIDI są transponowane względem tej wysokości.
